# connexio

Интерактивная лаборатория по физике средств связи: как сообщение добирается от телефона, компьютера или радиостанции до получателя.

Сайт целиком в одном файле `index.html`, без сборки и зависимостей. Достаточно открыть его в браузере.

## Что внутри

- **Симулятор сигнала**: смартфон, ПК, ноутбук, рация, спутниковая тарелка и сервер с оптоволокном. Расстояние, мощность, препятствия и помехи меняют потери, отношение сигнал/шум и количество ошибок в переданном сообщении.
- **Виды связи**: радио, сотовая сеть с хэндовером, спутники на разных орбитах, оптоволокно, Wi-Fi и Bluetooth, проводная линия.
- **Лаборатория**: шесть опытов (длина волны, время прохождения, аналог и цифра, затухание, модуляция, дискретизация).
- **Калькуляторы**: длина волны, время загрузки, задержка, бюджет радиолинии, предел Шеннона, децибелы, длина антенны, эффект Доплера, оптоволокно.
- **История**, **сравнение технологий** и **тест** из 24 вопросов.

Модели упрощённые, но используют реальные справочные константы.

## Запуск

Открыть `index.html` в браузере. Для публикации подходит GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
